# Artwork

`omarchy-wordmark.png` is a monochrome print rendering of Omarchy's official
wordmark. It is derived from
`default/plymouth/logo.png` in the
[Omarchy repository](https://github.com/basecamp/omarchy), with its RGB
channels changed to black and its transparency preserved.
